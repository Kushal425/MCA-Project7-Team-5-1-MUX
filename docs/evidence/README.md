# Verification Evidence & Artifacts (`docs/evidence/`)

This directory stores authentic verification evidence generated during simulation runs:
- Simulation execution logs (`.log`, `.txt`)
- Waveform screenshots illustrating key timing transitions (hits, misses, refills, LRU updates)
- VCD traces deliberately curated for milestone reviews

> [!IMPORTANT]
> Only actual, reproducibly generated simulation evidence may be committed here. Synthetic or fabricated evidence is strictly prohibited.
