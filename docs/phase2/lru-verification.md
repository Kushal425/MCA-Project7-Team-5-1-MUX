## 1. Independent Verification Architecture

To verify [`rtl/cache_2way_store.v`](../../rtl/cache_2way_store.v) without duplicating its internal 1-bit `lru_bit` implementation, [`tb/tb_cache_2way_store_stress.sv`](../../tb/tb_cache_2way_store_stress.sv) implements an independent **ordered-pair recency scoreboard** per set:

- For each set $s \in \{0,1,2,3\}$, the scoreboard maintains:
  - `sb_count[s]` $\in \{0, 1, 2\}$ (number of valid resident entries)
  - An ordered pair of resident slots `[0]` and `[1]`, each storing `{valid, tag[25:0], data[127:0], way}`:
    - `sb_count[s] == 0`: set is empty; expected `victim_way = 1'b0` (empty Way 0 priority).
    - `sb_count[s] == 1`: `[0]` holds the lone resident entry; expected `victim_way = ~sb_way[s][0]` (empty Way 1 priority after Way 0 is filled).
    - `sb_count[s] == 2`: `[0]` is the **LRU** (oldest) entry and `[1]` is the **MRU** (newest) entry; expected `victim_way = sb_way[s][0]`.
- On every fill into a full set, `[0]` is evicted, `[1]` shifts into `[0]` (becoming LRU), and the newly filled block is placed at `[1]` (MRU) in the evicted physical way.
- On `touch_en = 1`, `[0]` and `[1]` are swapped **only** when the address matches `[0]` (the LRU entry); touching `[1]` (MRU) or missing leaves recency unchanged.
- Combinational lookups (`touch_en = 0, fill_en = 0`) never modify scoreboard or DUT state.
- Every block generated by `make_distinct_block` carries globally unique 128-bit contents with four distinct non-zero 32-bit words (`w0..w3`), ensuring word-mux bugs or cross-way/cross-set aliasing fail immediately.
- Every mismatch prints the fixed seed, step index, phase, decoded address fields, DUT outputs vs. scoreboard expectations, and the set's ordered-pair state before terminating via `$fatal(1, ...)`. A `5 ms` simulation watchdog also terminates with `$fatal(1, ...)`.

## 2. Targeted Coverage & Stress Scope

`tb/tb_cache_2way_store_stress.sv` runs two phases in a single simulation:

1. **Phase 1 — Targeted Coverage Suite (`run_targeted_coverage_suite`)**
   - **Invalid-way priority & word offsets:** Across all 4 sets, checks cold `victim_way == 0`, fills Way 0, checks `victim_way == 1` and all 4 word offsets on Way 0, fills Way 1, and checks `victim_way == 0` and all 4 word offsets on Way 1.
   - **Both victim directions & `touch_en` edge cases:** Exercises `touch_en` on an already-MRU entry (no-op), `touch_en` on a miss (no-op), Way 0 eviction (`victim_way == 0`), `touch_en` flipping LRU→MRU in both directions (`Way 0` and `Way 1`), and Way 1 eviction (`victim_way == 1`).
   - **Cross-set independence:** Populates all 4 sets simultaneously (8 distinct blocks), mutates Sets 1 and 3, and sweeps Sets 0 and 2 across all 4 word offsets to verify zero cross-set corruption.
   - **Combinational lookups without enable:** Sweeps Way 0, Way 1, and miss addresses within a single cycle (`touch_en = 0, fill_en = 0`, no clock edge) and across clock cycles to confirm combinational lookup behavior without state mutation.
   - **Reset after fills:** Asserts synchronous `rst = 1` after all 8 slots across all 4 sets are populated, verifies complete invalidation (`hit = 0, hit_way = 0, read_word = 0, victim_way = 0`), and confirms fresh fills restart from Way 0.
2. **Phase 2 — Fixed-Seed Randomized Stress (`run_random_stress`, 2,000 steps)**
   - Uses an explicit 32-bit `xorshift32` PRNG seeded with fixed default seed `0x5a7c1357` (`1518080855`) to drive weighted pure combinational lookups, hits/misses with `touch_en`, fills/evictions, periodic mid-run resets, and 100-step cross-set combinational sweeps.

No defects were observed in [`rtl/cache_2way_store.v`](../../rtl/cache_2way_store.v).

## 5. Worked LRU Example (Set 0 Ordered-Pair Walkthrough)

This walkthrough traces **Set 0** through Phase 1 of [`tb/tb_cache_2way_store_stress.sv`](../../tb/tb_cache_2way_store_stress.sv), comparing the independent ordered-pair scoreboard `[LRU, MRU]` against `cache_2way_store`'s outputs (`victim_way`, `hit`, `hit_way`):

| Step | Stimulus on Set 0 | Ordered Pair `[0]=LRU, [1]=MRU` (After Clock) | `count` | Next `victim_way` | Why |
| --- | --- | --- | :---: | :---: | --- |
| 1 | `rst = 1` | `empty` | `0` | `0` | Cold set gives empty Way 0 priority. |
| 2 | `fill_en = 1`, `tag = T0` (`0x0010010`) | `[0] = (T0, Way 0)` | `1` | `1` | `T0` fills Way 0; Way 1 is still empty, so `victim_way = 1`. |
| 3 | Pure lookup `T0` across words `0..3` (`touch_en = 0, fill_en = 0`) | `[0] = (T0, Way 0)` | `1` | `1` | Combinational read hits Way 0 (`hit=1, hit_way=0`); state unchanged. |
| 4 | `fill_en = 1`, `tag = T1` (`0x0010011`) | `[0] = (T0, Way 0)`, `[1] = (T1, Way 1)` | `2` | `0` | `T1` fills empty Way 1 as MRU; `T0` in Way 0 becomes LRU (`victim_way = 0`). |
| 5 | `touch_en = 1`, `tag = T1` (hit on MRU) | `[0] = (T0, Way 0)`, `[1] = (T1, Way 1)` | `2` | `0` | Touching `[1]` (already MRU) is a no-op; Way 0 stays LRU. |
| 6 | `touch_en = 1`, `tag = T5` (miss) | `[0] = (T0, Way 0)`, `[1] = (T1, Way 1)` | `2` | `0` | `touch_en` on a miss must not perturb LRU order. |
| 7 | `fill_en = 1`, `tag = T2` (`0x0010012`) | `[0] = (T1, Way 1)`, `[1] = (T2, Way 0)` | `2` | `1` | Evicts `[0]` (`T0` in Way 0); `T1` shifts to LRU (`[0]`); `T2` enters Way 0 as MRU (`[1]`), so `victim_way` flips to `1`. |
| 8 | `touch_en = 1`, `tag = T1` (hit on LRU) | `[0] = (T2, Way 0)`, `[1] = (T1, Way 1)` | `2` | `0` | Touching `[0]` swaps the ordered pair: `T1` moves to MRU, `T2` becomes LRU (`victim_way = 0`). |
| 9 | `touch_en = 1`, `tag = T2` (hit on LRU) | `[0] = (T1, Way 1)`, `[1] = (T2, Way 0)` | `2` | `1` | Touching `[0]` promotes `T2` back to MRU and sets `T1` in Way 1 as LRU (`victim_way = 1`). |
| 10 | `fill_en = 1`, `tag = T3` (`0x0010013`) | `[0] = (T2, Way 0)`, `[1] = (T3, Way 1)` | `2` | `0` | Evicts `[0]` (`T1` in Way 1); `T2` survives in Way 0 as LRU; `T3` occupies Way 1 as MRU (`victim_way = 0`). |
| 11 | `rst = 1` (after all 4 sets filled) | `empty` | `0` | `0` | Synchronous reset clears all valid bits and resets `victim_way = 0` across all 4 sets. |
